# Gói 1 việc SuperWin — 500.000đ

Bộ bán và giao dịch vụ: làm hộ **một việc lặp** cho văn phòng, giáo viên, đội xây dựng.

## File

| File | Dùng để |
|------|---------|
| `index.html` | Trang bán + form tạo tin Zalo |
| `van-hanh.html` | Checklist và kịch bản nội bộ |
| `mau-sop.md` | SOP 1 trang giao khách |

## Việc cần làm ngay (5 phút)

1. Mở `index.html`, sửa 3 dòng `CONFIG` ở cuối file: số Zalo, ngân hàng, số TK.
2. Gửi `index.html` cho khách hoặc mở bằng Chrome.
3. Mỗi đơn: copy tin trong `van-hanh.html` → nhận CK → giao đúng checklist.

Không: app, AutoCAD, chạy ads, làm cả hệ thống công ty.
